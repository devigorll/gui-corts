# ✂️ Gui Corts - Landing Page

Uma landing page moderna, responsiva e interativa desenvolvida exclusivamente para a barbearia **Gui Corts**. O projeto foi construído focando em uma excelente experiência do usuário (UX), com alternância de temas, navegação fluida e carrossel de exibições.

## 🚀 Tecnologias Utilizadas

O projeto foi construído utilizando tecnologias puras (Vanilla Web Stack), garantindo leveza e alto desempenho:

* **HTML5**: Estruturação semântica do projeto.
* **CSS3**: Estilização moderna com suporte a temas e responsividade total.
* **JavaScript (ES6+)**: Lógica da aplicação, dinamismo e interatividade.

## 📁 Estrutura do Projeto

A organização dos arquivos no repositório segue a seguinte estrutura:

```
gui-corts/
├── assets/
│   ├── icons/        # Ícones utilizados na página
│   └── images/       # Imagens de cortes, ambiente e logo
├── css/
│   ├── responsive.css# Regras de mídia e adaptações para mobile/tablet
│   ├── style.css     # Estilos gerais da landing page
│   └── themes.css    # Variáveis e estilos para suporte a temas (claro/escuro)
├── js/
│   ├── carousel.js   # Lógica do carrossel/slider de fotos
│   ├── config.js     # Configurações gerais do projeto
│   ├── main.js       # Script principal de inicialização
│   ├── navigation.js # Comportamento de navegação e menu
│   └── theme.js      # Gerenciamento de troca de tema (Light/Dark mode)
├── index.html        # Arquivo principal da landing page
└── README.md         # Documentação do projeto
```

## ✨ Funcionalidades

* [x] **Design Responsivo**: Adaptado para telas mobile, tablets e desktops.
* [x] **Alternância de Temas (Theme Switcher)**: Permite ao usuário escolher entre diferentes temas visuais (ex: Modo Claro / Escuro).
* [x] **Carrossel Interativo**: Exibição dos serviços, cortes e fotos da barbearia.
* [x] **Navegação Dinâmica**: Scroll suave entre as seções da página.
